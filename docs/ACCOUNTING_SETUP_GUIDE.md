# دليل إعداد وتوجيه الحسابات المحاسبية لنظام إدارة الكهرباء (Utility ERP)

لضمان توجيه القيود المحاسبية والفواتير إلى الحسابات الصحيحة (مثل إيرادات الغرامات، الخصومات، رسوم النظافة، إيرادات الطاقة)، يجب اتباع الخطوات التفصيلية التالية لإعداد النظام:

## 1. المتطلبات الأساسية (إنشاء الحسابات في الدليل المحاسبي)
قبل ربط الحسابات في إعدادات النظام، يجب التأكد من وجودها في الدليل المحاسبي (Chart of Accounts).
- اذهب إلى: **المحاسبة (Accounting) -> التهيئة (Configuration) -> الدليل المحاسبي (Chart of Accounts)**.
- تأكد من إنشاء الحسابات التالية (إذا لم تكن موجودة، قم بإنشائها):
  - **حساب إيرادات الطاقة** (نوع الحساب: Income/إيرادات).
  - **حساب إيرادات الغرامات** (نوع الحساب: Income/إيرادات أو Other Income).
  - **حساب الخصومات الممنوحة (الجهات الداعمة)** (نوع الحساب: ذمم مدينة / Accounts Receivable)، حيث يتم تحميل الخصم وإثبات مديونيته على الجهة الداعمة (Sponsor).
  - **حساب رسوم النظافة والمجالس المحلية** (نوع الحساب: Current Liabilities/التزامات متداولة - إذا كانت مبالغ تُحصل لصالح جهات حكومية وتورد لهم).
  - **حساب التأمينات والودائع** (نوع الحساب: Current Liabilities/التزامات متداولة).

## 2. ربط الحسابات المتخصصة في إعدادات نظام الكهرباء (Utility ERP)
لربط البنود التلقائية (الغرامات، الخصومات، التسويات، التأمينات) بحساباتها المحاسبية، اتبع الآتي:
- اذهب إلى: **نظام الكهرباء (Utility ERP) -> التهيئة (Configuration) -> إعدادات النظام (Settings)**.
- مرر لأسفل للوصول إلى قسم **"الحسابات المحاسبية"**.
- قم بتحديد الحسابات المطلوبة في الحقول التالية:
  - **حساب إيرادات الغرامات (Fine Account):** حدد الحساب المحاسبي الخاص بالغرامات.
  - **حساب الخصومات (Discount Account):** حدد الحساب المحاسبي المخصص لتحمل الخصومات.
  - **حساب التأمينات (Deposit Account):** حدد حساب التزامات التأمينات للعملاء.
  - **حساب التسويات المالية (Settlement Account):** حدد حساب الإيرادات/المصروفات الخاص بتسويات الأرصدة.

## 3. ربط المنتجات (الخدمات) بحسابات الإيرادات
بالنسبة للبنود الأساسية مثل (استهلاك الطاقة، الرسوم الثابتة، رسوم النظافة والمجالس المحلية)، يتم توجيهها بناءً على إعدادات "المنتج" نفسه:
- اذهب إلى: **المبيعات (Sales) -> المنتجات (Products)**، أو من خلال إعدادات نظام الكهرباء التي تحدد منتجات الرسوم.
- افتح المنتج المعني (مثال: "تعرفة كيلووات"، "رسم نظافة"، "رسم ثابت").
- في تبويب **"المحاسبة" (Accounting)** الخاص بالمنتج:
  - في حقل **"حساب الدخل" (Income Account):** حدد الحساب المحاسبي المناسب (مثال: للإيرادات "حساب مبيعات الطاقة"، لرسوم النظافة "حساب أمانات رسوم النظافة").
  - *ملاحظة:* إذا تُرك هذا الحقل فارغاً، سيأخذ النظام الحساب الافتراضي من "فئة المنتج" (Product Category).

## 4. التحقق والاعتماد (الاختبار)
بعد الانتهاء من الإعدادات السابقة:
1. قم بإنشاء قراءة جديدة لعداد (تحتوي على استهلاك عالي لضمان صدور فاتورة).
2. قم بتطبيق "خصم" أو إضافة "غرامة" للاختبار.
3. اعتمد القراءة وقم بتوليد الفاتورة (Generate Bill).
4. اذهب إلى الفاتورة المحاسبية (Invoice) الناتجة وراجع تبويب **"عناصر مسودة القيد" (Journal Items)**.
5. ستلاحظ أن:
   - سطر "الاستهلاك" موجه لحساب إيرادات الطاقة.
   - سطر "الخصم" موجه لحساب الخصومات، ويتم تحميله محاسبياً على بطاقة الشريك (الجهة الداعمة - Sponsor).
   - سطر "الغرامة" موجه لحساب إيرادات الغرامات.

بمجرد ظهور القيود بالشكل الموضح أعلاه، فإن التوجيه المحاسبي يعمل بشكل سليم 100%.

## 5. أمثلة على القيود المحاسبية الناتجة (Journal Entries)

عند إصدار وتأكيد فاتورة مبيعات كهرباء تحتوي على استهلاك، رسوم، غرامات، وخصومات، يقوم النظام آلياً بتوليد القيد المحاسبي المجمع التالي:

### أ. قيد إصدار الفاتورة (استحقاق الفاتورة)
| الحساب المحاسبي (Account) | مدين (Debit) | دائن (Credit) | الوصف (التوجيه) |
|--------------------------|-------------|--------------|-------|
| **حساب ذمم المشتركين (العملاء)** | 10,500 | | إجمالي المبلغ الصافي المطلوب من المشترك سداده |
| **إيرادات مبيعات الطاقة** | | 8,000 | قيمة استهلاك الكيلووات (حسب المنتج) |
| **إيرادات الرسوم (ثابتة / خدمة)** | | 1,000 | رسوم الاشتراك الشهري (حسب المنتج) |
| **إيرادات الغرامات والمخالفات** | | 1,500 | يتم توجيهه بناءً على إعداد `fine_account_id` |
| **حساب أمانات النظافة / المجالس**| | 500 | مبالغ لصالح جهات أخرى (حسب المنتج) |
| **حساب الخصومات الممنوحة (الجهة الداعمة)** | 500 | | يُوجه حسب إعداد `discount_account_id` ويُسجل كمديونية على (الجهة الداعمة) |

*(ملاحظة: إجمالي الجانب المدين = 11,000 وإجمالي الجانب الدائن = 11,000 مما يحقق توازن القيد)*

### ب. قيد السداد (التحصيل من المشترك)
عند قيام المشترك بسداد الفاتورة (وليكن السداد كاملاً لمبلغ 10,500):
| الحساب المحاسبي (Account) | مدين (Debit) | دائن (Credit) | الوصف (التوجيه) |
|--------------------------|-------------|--------------|-------|
| **حساب الصندوق / البنك** | 10,500 | | المبلغ المحصل فعلياً إلى الخزينة |
| **حساب ذمم المشتركين (العملاء)** | | 10,500 | إقفال مديونية المشترك |
